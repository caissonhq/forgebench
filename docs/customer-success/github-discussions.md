# GitHub Discussions Setup

Enable Discussions on `caissonhq/forgebench` with categories:

| Category | Purpose |
|----------|---------|
| **Announcements** | Releases, EA updates |
| **General** | Questions, workflows |
| **Ideas** | Feature requests |
| **Show and tell** | Benchmark results, policy patterns |
| **Support** | Team tier — tag with license tier in post |

## Pinned welcome post

Welcome to ForgeBench Discussions.

- **New here?** Run `forgebench demo` and read [Quickstart](https://forgebench.dev/quickstart/)
- **Team customers:** include your license ID (from `forgebench license status`) in support posts
- **Bugs:** open a GitHub Issue with `forgebench doctor` output

ForgeBench does not prove code is safe. It highlights merge risk before AI-generated code reaches main.
