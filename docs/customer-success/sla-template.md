# Support SLA Template (Team / Enterprise)

## Coverage

| Tier | Hours | Channels |
|------|-------|----------|
| **Team** | Business hours (customer TZ) | GitHub Discussions, email |
| **Enterprise** | 24×5 or 24×7 (contract) | Above + dedicated Slack/Teams channel |

## Response targets

| Severity | Definition | Team | Enterprise |
|----------|------------|------|------------|
| **P1** | Production CI gate down | 4h | 1h |
| **P2** | Feature degraded, workaround exists | 1 business day | 4h |
| **P3** | Question, docs, enhancement | 3 business days | 1 business day |

## In scope

- ForgeBench CLI, IDE extensions, GitHub Action
- License activation and seat issues
- Policy configuration guidance
- Self-hosted GitHub App kit (Enterprise)

## Out of scope

- General agent debugging
- Customer application code review
- Hosted ForgeBench SaaS (not offered)

## Escalation

1. GitHub Discussions tag `support`
2. Email hello@forgebench.dev with license ID
3. Enterprise: named CSM contact
